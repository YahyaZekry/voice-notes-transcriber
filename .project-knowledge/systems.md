# Systems

> Part of voice-notes-transcriber/.project-knowledge/ | Last updated: 2026-08-11

| System | Status | Details |
|--------|--------|---------|
| Transcription engine | Live | faster-whisper `large-v3`, **CUDA + float16** (since 2026-08-11), lazy model load (~40s cold from cache), ~5.4 GB VRAM resident while loaded (whisper + torch CUDA runtime; of 7.7 GB usable). `vad_filter=True`, auto language detect, `word_timestamps=True` (needed for speaker-word assignment). GPU speedup: a 10-min note now transcribes in ~3–5 min vs. never-finishing on CPU int8. |
| Speaker diarization | Live | pyannote `speaker-diarization-3.1` (gated models, needs `HF_TOKEN`). Runs on **CUDA** (pipeline `.to('cuda')`, waveform moved to CUDA). **After every note the pipeline is moved back to CPU + `torch.cuda.empty_cache()`** so the next whisper run has full VRAM (a resident GPU pyannote pushed whisper into CUDA OOM on a 7.7 GB GPU). Auto speaker count with a probe fallback: if auto returns 1 speaker on ≥10s of speech, re-run with `num_speakers=2` and accept only when the minority voice ≥10% of speech AND ≥4s (catches dominance-collapse; avoids splitting monologues). Labels added only when >1 distinct voice. **Known limit (verified 2026-08-10):** rapid-fire Q&A with 0.3–1s interjections under a dominant voice — the segmentation model never registers the interjections as a second speaker, so short answers merge into the dominant speaker's turns. Long utterances of both speakers label correctly. Falls back to plain transcript on any failure. |
| File watching | Live | watchdog `Observer`, `recursive=False`, scans existing files at startup then watches `on_created`/`on_moved`. Only direct children of the root are processed (subdir events like `Completed/` are ignored). Stability gate: file must be idle (mtime age ≥ 5s) AND size unchanged across polls, up to 10 min (protects against mid-write files, e.g. an active screen recording). Caveat (observed 2026-08-11): a file renamed **while** it is mid-transcription breaks that run (note may be written under the old name; the renamed file is left unprocessed until the service restarts). |
| Notifications | Live | `notify()` helper → `notify-send` (fallback `kdialog --passivepopup`), never raises. Fires on: found voice note, skipped (still writing), transcription failed, could not write note, and transcription complete (with duration + language). Toggle with `TRANSCRIBER_NOTIFY=0`. |
| Service / boot | Live | systemd --user `voice-transcriber.service`, `Restart=on-failure`, `WantedBy=default.target` (starts at login). Unit sets `Environment=LD_LIBRARY_PATH=<repo>/.ct2-cuda/lib:<repo>/.cuda13/lib64`. Idles at ~20 MB RAM + ~5.4 GB VRAM once the model has loaded (model stays resident until the service is restarted). |
| Model download | Live | HuggingFace hub, unauthenticated (~3 GB cache at `~/.cache/huggingface/`). |
